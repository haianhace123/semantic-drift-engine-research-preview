# Security Policy

## Supported versions

This repository is a research preview. No public deployment support or response
SLA is promised. Security fixes, if available, will be released against the
latest tagged version.

## Reporting a vulnerability

Please use GitHub's **private vulnerability reporting** feature if enabled on
this repository. Do not disclose exploit details in public issues. The maintainer
will review reports as capacity permits.

## Scope

Only the reviewed release source is published. It is not a security certification.
Avoid exposing preview deployments to untrusted internet traffic without
independent deployment and authentication review.
